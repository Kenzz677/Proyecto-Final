2. Fundamentos de la Automatización

Todo sistema de control se divide en tres etapas fundamentales[cite: 1]:


  • 1. Detectar: El sensor ultrasónico HC-SR04 mide el tiempo de vuelo del pulso de sonido para determinar la distancia de un visitante (rango de 2 a 400 cm)[...]
  • 2. Procesar: El microcontrolador ATmega328 del Arduino Uno R3 compara la medición contra un umbral crítico establecido en 60 cm[cite: 1].
  • 3. Alertar: Se activan los actuadores de señalización (LED rojo y buzzer piezoeléctrico) en forma coordinada ante una intrusión[cite: 1].

4. Programa C++ y Lógica Tinkercad

Implementación en C/C++ probada de forma virtual dentro del entorno Tinkercad Circuits[cite: 1]:

#define LedVerde 8
#define LedRojo 12
#define FotoRe A0
#define Button A1
#define Buzzer 7

int CantidadLuz = 400;
bool alarmaActivada = false;
int estadoAnteriorBoton = HIGH;

void setup() {
    pinMode(LedVerde, OUTPUT);
    pinMode(LedRojo, OUTPUT);
    pinMode(FotoRe, INPUT);
    pinMode(Button, INPUT_PULLUP);
    pinMode(Buzzer, OUTPUT);

    digitalWrite(LedVerde, HIGH);
    digitalWrite(LedRojo, LOW);
    noTone(Buzzer);

    Serial.begin(9600);
    Serial.println("IRTRA GUARD Inicializado");
}
